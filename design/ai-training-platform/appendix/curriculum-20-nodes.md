# 附录 · 20 节点课程定稿

> 与 V1 原方案的差异：原方案 Node 1（邮件清零）作为破冰难度过高，新方案插入"Node 1: AI 自我介绍"作为破冰，原 Node 1 顺延为 Node 2。整体保持 20 关结构。

每个节点的字段：

- **slug** — DB 主键
- **phase** — 所属阶段（4 阶段各 5 节点）
- **难度** — 1–5 星
- **时长** — 默认 `duration_sec`
- **工具** — 推荐与替代矩阵
- **提交格式** — SDUI input.kind
- **投票判分** — 同侪应该看什么

## 阶段一 · 信息破冰与日常效率重构（Node 1–5）

### Node 1 · AI 自我介绍

| 字段 | 值 |
| --- | --- |
| slug | `node-01-ai-self-intro` |
| phase | icebreak |
| 难度 | ★ |
| 时长 | 90 秒 |
| 工具 | ChatGPT / Claude（任意可用即可） |
| 替代 | 文心一言 / 通义千问 / 智谱清言 |
| 提交格式 | 单行文本（≤ 200 字） |
| 投票判分 | "哪个夸夸最有梗？" |

**题目**：
> 让 AI 用 50 字以内做一段你的"夸夸介绍"。

**一键复制提示词**：
```
你是一个热情的活动主持人，请用 50 字以内、有趣的语气，
介绍一位叫做 "{participant.display_name}" 的 AI 学习者，
让 ta 即将出场。
```

**新手陷阱提示**：
> 直接粘贴上面这段就好，把 AI 的回答原样粘回这里。

**设计意图**：保证 95% 学员能在 90 秒内成功提交，建立"我也能玩 AI"的初体验。

## 题库扩展机制

V1 上线时 1 套 20 题。V2 起教研可创建多个"主题包"：

- **职场基础包** （当前版本）
- **教师/教研版**（替换 Node 9 营销为 Node 9 教学设计）
- **创业者版**（更重 Node 16 自动化与 Node 20 飞轮）
- **大学生版**（替换 Node 7 数据分析为 Node 7 论文助手）

主题包通过 `curriculum_packs` 表（V2 引入）管理，复用所有 SDUI 渲染器。
