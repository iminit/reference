## 2. XP/积分经济

### 2.1 设计目标

- 不能因为"前三关赢家通吃"而让 70 分起后追赶者放弃
- 不能因为"全员鼓励"而让顶尖玩家觉得无聊
- 单局总分要有清晰区分度，但不能让最差的低于"参与奖"门槛

### 2.2 XP 公式

每个节点的 XP 由四部分组成：

```
XP_node = (
    base                          // 提交奖：100
  + speed_bonus                   // 速度奖：0 ~ 50
  + peer_vote_bonus               // 同侪奖：每票 30，封顶 5 票 = 150
  + difficulty_multiplier         // 难度系数：1.0–1.5
)

× streak_multiplier               // 连续提交加成（详见 2.4）
```

具体规则：

```ts
speed_bonus(rank_in_node):
  rank == 1                       → 50  + 闪电徽章
  rank in [2, 3]                  → 30
  rank in [4, 10]                 → 15
  else                            → 0

peer_vote_bonus(votes_received):
  min(votes_received, 5) * 30

difficulty_multiplier(node_seq):
  node_seq in [1..5]              → 1.0
  node_seq in [6..10]             → 1.1
  node_seq in [11..15]            → 1.2
  node_seq in [16..19]            → 1.35
  node_seq == 20                  → 1.5
```

### 2.3 数值校准

20 个节点全部满分参与者：

```
理论上限 = 20 × (100 + 50 + 150) × 平均难度系数 1.16
        ≈ 6,960 XP
```

"参与即拿"的下限（每节都交、零票、零速度奖）：

```
下限 = 20 × 100 × 1.16 ≈ 2,320 XP
```

实测拟定（按 90% 完课率、平均每节获 1.5 票）：

```
中位数 ≈ 3,500 XP
P75   ≈ 4,200 XP
P95   ≈ 5,400 XP
```

这意味着：
- 颁奖榜单 P95（前 5%）比中位数高约 54%——区分度足够
- 中位数比下限高约 51%——证明"努力是有用的"
- 但下限 2,320 也是"绿色的"——不会让任何人 0 分难堪

### 2.4 连续提交的"温柔"streak

**反直觉决策**：不做 Duolingo 那种"断一次清零"的硬 streak。

原因：
- 这是 2 小时的单场，断了就只剩 1.5 小时，惩罚太重
- 学员可能因为"AI 工具配置问题"漏交一两关，惩罚他们就是惩罚平台自己

替代方案——"温和动量"：

```
连交 3 关 → 后续每关 XP × 1.05（解锁"小猎犬"徽章）
连交 7 关 → 后续每关 XP × 1.10（"稳步攀登者"徽章）
连交 12 关 → 后续每关 XP × 1.15（"心流大师"徽章）
连交 20 关 → 翻倍系数 × 1.25 + "全勤先锋"徽章

中断 1 关 → 系数 ×0.9（不归零），可在下一关恢复
中断 2 关 → 系数 ×0.7，但仍有 streak 历史
中断 3 关 → 系数清零，从头开始
```

这种衰减式 streak 的关键是**"宽恕一两次失误，但奖励长期坚持"**。

## 3. 徽章图谱

### 3.1 徽章 ≠ XP

徽章是**收藏品**，XP 是**计分器**。徽章上不上榜不重要，**徽章本身是炫耀资本**。

设计目标：
- 总数 24 枚，每场最多解锁 18 枚（保持稀缺感）
- 至少 3 枚是"全员可得"（基础参与），保证人人有

### 3.2 徽章六大类

```
🏃 速度系（4）
   闪电 ⚡：节点首位提交
   闪电×3 ⚡⚡⚡：累计 3 次首位
   极速王 🏆：累计 5 次首位
   秒针 🕘：节点开放 30 秒内提交

❤️ 共识系（4）
   被看见 👀：单节点收到 ≥3 票
   人气王 ⭐：单节点收到 ≥5 票（封顶）
   全场最爱 💖：累计获票数前 5%
   连胜 🔥：连续 3 节点都进前 5 名

🧠 心流系（4）
   小猎犬 🐕：连续 3 关提交
   稳步攀登者 🏔️：连续 7 关提交
   心流大师 🧘：连续 12 关提交
   全勤先锋 🌟：20 关全勤

🎨 多面手系（4）
   笔尖客 ✍️：完成 5 个文本类节点
   画师 🎨：完成 4 个多模态节点
   智者 🦉：完成 5 个智能体节点
   通才 🌈：四大阶段都至少完成 4 关

🎁 慷慨系（4）
   伯乐 🐎：投票为某人带来"被看见"
   评审团 ⚖️：用满 60 张选票（20 关 × 3 票）
   早期投资人 💎：投了一个最终获奖者的早期作品
   救火队 🚒：在最后 10 秒内投票

🎖️ 至高系（4，每场最多 3 人）
   AI 应用先锋 🥇：全场 XP 第 1
   亚军徽 🥈：全场 XP 第 2
   季军徽 🥉：全场 XP 第 3
   黑马 🐎：从 P50 之后跃升至前 3
```

### 3.3 徽章获取的"通知"设计

徽章解锁不能用模态弹窗（打断答题），用**屏幕底部 toast + 主页底栏闪光**：

```
┌─────────────────────────────────────────┐
│                                          │
│      [当前节点内容]                       │
│                                          │
│                                          │
│  ╔═══════════════════════════════════╗  │
│  ║  ⚡ 你刚解锁：闪电                  ║  │
│  ║  全场首位提交！+50 XP              ║  │
│  ╚═══════════════════════════════════╝  │
│  ────────────────────────────────────── │
│  地图  徽章·NEW   排行   我的            │
└─────────────────────────────────────────┘
```

3 秒后 toast 滑走，但底部 "徽章" tab 持续闪烁，直到用户点击查看。

## 4. 投票系统的博弈论防护（解决风险 #5）

### 4.1 攻击面

| 攻击类型 | 现实场景 | 杀伤力 |
| --- | --- | --- |
| **同伴互投** | 三人小群约好互投 | 中（污染排行榜） |
| **机器人刷票** | 脚本一次投 100 票 | 高（破坏整场） |
| **从众偏差** | 先上榜者无脑被投 | 中（早期提交占便宜） |
| **空白投票** | 用户随手投，破坏区分度 | 低（噪声） |

### 4.2 vote_weight 算法

每张票不是 1，而是有动态权重：

```ts
vote_weight = base_weight                    // 1.0
            × voter_quality_factor           // 0.5–1.5
            × time_decay_factor              // 0.6–1.0
            × diversity_bonus                // 1.0–1.2
            × anti_collusion_penalty         // 0.0–1.0
```

**voter_quality_factor**：投票者本人在过去节点的表现
```ts
voter_quality_factor =
  0.5 if voter_total_xp < P25
  1.0 if voter_total_xp in [P25, P75]
  1.3 if voter_total_xp in [P75, P95]
  1.5 if voter_total_xp >= P95
```
"评委的水平决定了票的含金量"——这是 IMDb 加权平均的思路。

**time_decay_factor**：投票的时机
```ts
time_decay_factor =
  1.0 if voted_in_first_50%_of_voting_window
  0.8 if voted_in_50%–80%
  0.6 if voted_in_last_20%
```
鼓励"早思考、早投票"，惩罚"看到大家投谁我也投谁"的从众。

**diversity_bonus**：你的票是否分散
```ts
voter_diversity = unique_recipients / total_votes_cast
diversity_bonus = 1.0 + (voter_diversity - 0.7) * 0.5
              clamped to [1.0, 1.2]
```
你 60 张票全投给同一个人 → diversity 低 → bonus = 1.0
你 60 张票投给 40 个不同的人 → diversity 高 → bonus = 1.2

**anti_collusion_penalty**：互投惩罚
- 检测三元图：A→B、B→C、C→A 这种循环互投
- 检测对偶图：A→B 且 B→A，权重各 ×0.7
- 检测同 IP/同设备：完全归零

### 4.3 谁能投谁

强约束：**自己的提交不能投自己**（schema 层 CHECK）。

弱约束：
- 每节点 3 张选票
- 一张选票只能投一个提交
- 同一节点不能给同一人投两次

### 4.4 异常监控

主持人台后台有"投票健康度"指标：

```
正常：vote concentration in top 5 < 60%
正常：voter diversity > 0.65
异常：单 IP 投票 > 10 票/分钟
异常：collusion ring detected
```

主持人可一键"重置某节点投票"——但这是核选项，每场最多 2 次。

## 5. 潜水者拯救协议（解决风险 #3）

### 5.1 定义

**潜水者**：连续 2 个节点 0 提交，且过去 5 分钟有页面活动（不是离开页面）。

不抓离开页面的——他们已经走了，骚扰只会更糟。

### 5.2 四级递增介入

**Level 1（连续 2 关未交）：吉祥物轻推**

吉祥物从屏幕一角探头，气泡：

```
"嘿，要不试试一键复制提示词？
 就算只是粘贴一下，也能解锁'参与奖'徽章哦 🎁"
```

按钮：[一键复制] [我看看] [关掉这个]

**Level 2（连续 3 关未交）：降级题目**

当前节点出现"简化版"按钮：

```
┌─────────────────────────────────────┐
│ Node 7：情绪翻译器                    │
│                                      │
│ 💡 给你的备选简化版：                 │
│   把下面这段愤怒邮件复制到 AI 里，    │
│   说"请把这封邮件改得礼貌一些"        │
│   把 AI 的回答粘贴回来即可。           │
│                                      │
│   [一键复制 + 直达 ChatGPT]          │
└─────────────────────────────────────┘
```

简化版提交记 60 XP（少于 100，但远胜于 0）。

**Level 3（连续 5 关未交）：助教 DM**

后台触发助教手机推送，助教在群里 @ 该学员或私聊询问。
（这是社交介入，平台只负责报警，不自动消息骚扰）

**Level 4（连续 8 关未交）：邀请观摩**

弹窗：

```
"看起来今天 AI 工具不太顺手？
 你可以选择继续静静欣赏别人的精彩答案，
 我们会保留你今天的所有进度。
 散场后会有补习材料发给你。"

  [继续旁观] [我再试试]
```

这是"体面退场"——不强迫继续答题，但保留账号有效（仍可投票），并承诺会后内容。

### 5.3 关键设计哲学

潜水者拯救的核心**不是逼他们答题**，而是**让他们觉得参与有出路、退出有体面**。一个被"催到答题"的人会变成差评源，一个被"温柔对待"的人即使没答完也会推荐。

## 6. 中场设计（解决疲劳谷）

### 6.1 中场是 4 分钟，不是 5

经验数据：在线培训给 5 分钟休息，70% 人 6 分钟才回；给 4 分钟，65% 人 4 分钟整回。**先给紧一点，再延长 1 分钟更有效**。

### 6.2 中场不是"空白"

```
┌──────────────────────────────────────────────────┐
│                                                   │
│   🎬 你的前 10 关高光时刻                          │
│                                                   │
│   ▼ 自动播放 ▼                                    │
│   ┌──────────────────────────────────────────┐  │
│   │ "小李的 Node 3 提取摘要被 8 人点赞"        │  │
│   │   [展示原文……]                            │  │
│   └──────────────────────────────────────────┘  │
│                                                   │
│   排行榜实时刷新：                                │
│   #1 王XX  2,847 XP  ⚡⚡ 👀                       │
│   #2 李XX  2,693 XP  ⚡  💖                       │
│   #3 张XX  2,481 XP  🐕                          │
│   ...                                            │
│   #14 你   1,892 XP  👀  ← 距离前十还差 3 票     │
│                                                   │
│   ⏱  下一关开始：03:47                            │
│                                                   │
│   ☕ 趁机喝口水                                    │
└──────────────────────────────────────────────────┘
```

设计点：
- 自动播放"高光时刻"——免费的多巴胺
- 排行榜定位用户在哪里——制造"还能追"的预期
- 倒计时明确，避免散漫

### 6.3 第二阶段的调性反转

中场之后进入多模态阶段（Node 11–15），UI 主色从桃橙微微切到海蓝渐变背景，吉祥物换个动作（从坐姿到站姿），**让用户感觉"剧情翻篇了"**。

这是"分章感"的视觉表达——电影都有第二幕，培训也要有。

## 7. 颁奖典礼的三幕情绪曲线

### 7.1 三幕

```
幕 1：复盘（00:00–01:30）
  「过去两小时，我们一起完成了 20 道挑战。」
   ╲      数字滚动：
    总提交 1,247 条
    总投票 5,832 次
    解锁徽章 218 枚
    诞生了 23 个"高人气"作品
   ╱
  情绪：宏大、归属

幕 2：致敬（01:30–04:00）
  按徽章类别逐一致敬：
  「全勤先锋（解锁连续 20 关）：" + 列表」
  「黑马（中段反超前三）：……」
  「评审团（用满 60 票）：……」
  情绪：被看见

幕 3：加冕（04:00–06:00）
  ━━━━ 现在公布全场前三 ━━━━

  鼓点 → 烟花 → 第三名揭晓
  鼓点 → 烟花更大 → 第二名揭晓
  鼓点最强 → 全场烟花 → 第一名揭晓

  奖台 + 头像 + 数字奖章
  奖章上有用户暱称、时间戳、唯一序列号

  情绪：高潮
```

### 7.2 奖章是产品的"种子"

数字奖章必须：
1. **可下载** 1080×1920（朋友圈/小红书友好）
2. **唯一序列号** — 写在角落，强调"这是第 #042 场的全场冠军，全网仅此一枚"
3. **二维码** — 扫码进入 `/recap` 页，**任何人都能看冠军的 20 个作品**
4. **支持替换皮肤** — V5 引入主题季时复用

奖章本身就是"用户主动传播平台"的载体，它是产品获客的核心资产。

### 7.3 没拿前三的人怎么办

- 颁奖结束后，**所有人**都拿到自己的"个人成就单"——XP、徽章、最高赞作品
- 也是 1080×1920 海报，鼓励分享 ("我在 LightningClass 拿了 7 枚徽章" )
- 个人作品集页 `/recap/[user_id]` 也公开，被分享的链接展示用户全场的 20 个提交

**这一点决定了 NPS 上限**——拿不到第一也愿意推荐，才是好产品。

## 8. 反向设计：让顶尖玩家不无聊

中位数玩家关心"我能不能上榜"，但 P95 玩家两小时没挑战会觉得水。给他们三个"硬骨头"：

1. **隐藏徽章** — 不写在徽章列表里，比如"在 Node 11 用了 < 20 字的提示词且收到 > 5 票"
2. **加分挑战** — 主持人台可临场撒"双倍 XP 节点"（如本节点首位提交 ×2）
3. **彩蛋题** — 课程内插入 1–2 个"非标"挑战，例如"用 Node X 学的方法解决主持人提供的实时问题"

这些机制只对盯着进度条的人可见，对中位数玩家无感。

## 9. V3 摘要 / 关键决策

1. **情绪曲线设计** —— 6 峰 + 1 谷 + 第 65 分钟反扑
2. **XP 公式四部分** —— base + speed + peer_vote + difficulty × streak
3. **温柔 streak** —— 衰减不归零，鼓励长期坚持
4. **24 枚徽章六类** —— 速度/共识/心流/多面手/慷慨/至高
5. **vote_weight 五因子** —— 防共谋、防从众、奖励多元
6. **潜水者四级介入** —— 轻推 → 降级 → 助教 → 体面退场
7. **中场 4 分钟** —— 高光回放 + 排行榜 + 调性反转
8. **颁奖典礼三幕** —— 复盘 / 致敬 / 加冕
9. **奖章是产品种子** —— 可下载、可分享、带 recap 二维码
10. **顶尖玩家通道** —— 隐藏徽章、临场双倍、彩蛋
